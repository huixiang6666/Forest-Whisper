# Forest Whisper 森语

> A HarmonyOS sleep-aid music player built with ArkTS and ArkUI.  
> 一个基于 HarmonyOS 的助眠音乐播放器项目，面向助眠、放松与轻度社交场景。

---

## 项目简介

**Forest Whisper（森语）** 是一个基于 **HarmonyOS** 开发的音乐播放器应用，主要服务于助眠、专注与放松场景。项目围绕“轻量化音乐陪伴”这一目标，完成了**用户登录注册、歌曲推荐、音乐播放、搜索、收藏管理、动态展示**等核心业务功能。

本项目使用 **DevEco Studio** 作为开发平台，基于 **ArkTS + ArkUI** 构建页面与交互逻辑，并结合 **MediaKit** 实现音频播放能力，使用 **Preferences** 完成本地数据持久化，支持多页面之间的状态联动与用户数据管理。

---

## 技术栈

- **开发平台**：DevEco Studio
- **目标平台**：HarmonyOS
- **开发语言**：ArkTS / ETS
- **UI 框架**：ArkUI
- **页面导航**：NavPathStack、Tabs
- **状态管理**：AppStorageV2
- **音频能力**：MediaKit（AVPlayer）
- **数据持久化**：ArkData Preferences
- **应用框架能力**：AbilityKit
- **工程化支持**：Hvigor、json5 配置

## 核心功能

### 1. 音乐播放
- 支持歌曲播放、暂停、进度更新
- 支持上一首 / 下一首切换
- 支持播放列表管理
- 支持当前播放状态跨页面同步

- 支持用户注册与登录

### 3. 搜索功能
- 支持按歌曲名称搜索
- 支持按歌手名称搜索
- 支持搜索结果跳转播放页

### 4. 收藏管理
- 支持收藏 / 取消收藏歌曲
- 支持“我喜欢的音乐”歌单展示
- 支持不同用户收藏数据隔离

- 支持动态社区内容展示
- 支持用户个人页面信息展示

## 项目亮点

### 1. 封装播放器管理器
项目对音频播放能力进行了统一封装，基于 **AVPlayer** 实现播放器生命周期管理、状态监听、播放进度更新与歌曲切换逻辑，减少了页面之间的重复代码，提高了播放模块的复用性和稳定性。

### 2. 实现跨页面状态联动
通过 **AppStorageV2** 对当前播放歌曲、播放列表、播放索引、播放状态等信息进行全局管理，解决了页面切换后播放状态不一致的问题，提升了交互连贯性。

### 3. 完成本地数据持久化
基于 **Preferences** 实现用户登录信息、收藏数据等本地持久化存储，并通过用户维度对收藏数据进行隔离，避免不同账号之间的数据混淆。

### 4. 业务模块结构清晰
项目围绕播放、用户、收藏、搜索、动态等业务模块进行组织，便于后续继续扩展推荐算法、歌单系统、云端接口接入等能力。

---

## 主要模块说明

### 音乐播放模块
负责歌曲播放、暂停、上一首、下一首、播放进度更新、播放完成自动切换等逻辑。项目通过统一的播放器管理类集中处理音频相关事件，保证播放行为一致。

### 用户管理模块
负责注册、登录、当前用户信息读取与保存。该模块基于本地存储实现基础账号体系，适合课程设计与本地业务验证场景。

### 收藏模块
负责歌曲收藏、取消收藏、“我喜欢的音乐”歌单维护等功能。通过对收藏数据按用户区分存储，实现多用户之间的数据隔离。

### 搜索模块
负责对歌曲与歌手信息进行关键词检索，并将结果展示在列表中，支持点击结果后直接进入播放流程。

### 页面导航模块
负责推荐页、发现页、动态页、我的页面之间的切换与路由跳转，结合底部 Tabs 与页面栈管理实现整体导航逻辑。
